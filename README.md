# CodeAlpha Student Grade Tracker

## Description
A Java Swing application developed for the CodeAlpha Java Programming Internship. This application helps manage student grades and generates a summary report.

## Features
- Add student name
- Add student marks
- Store data using ArrayList
- Display all students
- Calculate average marks
- Display highest marks
- Display lowest marks
- GUI-based interface using Java Swing

## Technologies Used
- Java
- Java Swing
- ArrayList

## How to Run

1. Compile the program:
```bash
javac StudentGradeTrackerGUI.java
```

2. Run the program:
```bash
java StudentGradeTrackerGUI
```

## Output
The application allows users to:
- Enter student names and marks
- Add multiple students
- View a summary report showing:
  - Total Students
  - Total Marks
  - Average Marks
  - Highest Marks
  - Lowest Marks
